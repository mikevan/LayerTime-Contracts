# LayerTime-Contracts

Canonical application and Link wire contracts and test vectors for the C++, Kotlin and Monkey C bindings.


Source ancestry is recorded in `EXTRACTION.json`; original Git history remains in LayerTime. EXTRACTION.json records the initial local preparation; subsequent checkpoints are recorded in Git history.

Read [models](models.md), [commands](commands.md), [capabilities](capabilities.md), [Link 0.1](link.md), [Link 0.2](link_0_2.md), and the canonical [vectors](vectors/). These are common definitions and test data rather than a compiled code library. Core and Vixen protocol tests can use `LAYERTIME_CONTRACTS_DIR` to select this checkout.
